## 核心問題

Enterprise Architecture governance 長期碎片化在多個工具（Word、Confluence、PowerPoint）之間，缺乏系統化的模板、可追溯性和版本控制。大型組織（特別是 UK public sector）需要一個結構化的、AI-assisted 的工作流來覆蓋從原則制定、風險評估、採購到設計評審的完整生命週期。

## 核心方案

ArcKit 是一個 toolkit，以一組 **116 個 slash commands**（70 官方 + 46 community-contributed）覆蓋 EA 治理全流程，按階段組織：

1. **Template-driven generation** — 每個 command 對應一個 markdown template，通過 AI assistant（Claude Code 為一級平台）填入上下文後產出結構化 artifact
2. **Multi-AI 分發** — 同一套 commands 可部署到 Claude Code（plugin）、Gemini CLI（extension）、GitHub Copilot（prompt files）、Codex CLI / OpenCode CLI，cross-platform
3. **Phase 0–16 生命週期** — 從 project planning → principles → stakeholders → risk (Orange Book) → business case (Green Book SOBC) → requirements → data modeling → DPIA → technology research → Wardley mapping → vendor procurement → design review → backlog → ServiceNow → traceability → quality assurance → compliance assessment → documentation publishing
4. **Regulatory overlays** — UK Government（TCoP、Service Standard、NCSC CAF、Secure by Design、AI Playbook、ATRS、MOD JSP 936）+ EU（GDPR、NIS2、AI Act、DORA、CRA、DSA、Data Act）+ France（SecNumCloud、ANSSI、EBIOS、DINUM）+ Canada Federal（FITAA、PIA、ITSG-33、OCAP）+ UAE Federal（PDPL、IAS、UAE Pass、AI Charter）+ Austria（DSG、NISG、BVergG）
5. **10 autonomous research agents** — 用於 market research、data source discovery、cloud service evaluation 等，隔離在獨立 context window 中執行

## 架構要點

- **核心**: Claude Code plugin（`.claude-plugin/plugin.json`），5 bundled MCP servers（AWS Knowledge、Microsoft Learn、Google Developer Knowledge、Data Commons、govreposcrape）
- **Hooks 系統**: SessionStart（版本檢測）、UserPromptSubmit（project context 注入）、PreToolUse（ARC filename 自動修正）、PermissionRequest（MCP tools auto-allow）、Stop hooks（Wardley Map 數學檢查）
- **Monorepo 結構**: 包含 arckit-claude plugin + CLI tool（Python `pyproject.toml`）+ docs site + 147 vendored Wardley maps + scripts（bash/Python）
- **輸出格式**: Markdown artifacts 按 ARC-{project}-{type}-v{semver}.md 命名，Git 版本控制

## 風險與弱點

- ⚠️ **Claude Code 鎖定** — Premier experience 依賴 Claude Code 特有的 hooks、agents、MCP 功能。Copilot/Codex CLI 用戶只能拿到 commands + templates，缺失 agent delegation 和自動化 governance。這在 multi-AI 策略中形成了實際上的 vendor lock-in
- ⚠️ **文檔過長** — README 達 1,733 行，command reference 極其詳盡但新用戶 onboarding 成本高。ArcKit Book 已拆分到獨立 repo，是正確方向但尚未解決初始認知負擔
- ⚠️ **Community overlay 維護風險** — EU/French/Canada/UAE/Austria 等 regulatory overlay 標註為 community-contributed，部分 citation 標記 `[NEEDS VERIFICATION]`，且 solo-maintained（UAE）。合規產出依賴這些 overlay 的準確性，而 overlay 的維護沒有 SLA
- ⚠️ **Windows 支持有限** — hooks 依賴 bash/jq，native Windows 不可用。WSL2 是 workaround 而非 native support
- ⚠️ **測試覆蓋範圍** — 有 tests 目錄（plugin structure tests、handoff validation、graph utils），但 ~32MB repo 中 test 量相對小，且沒有看到端到端的 artifact 生成測試
- ⚠️ **v4.x 成熟度 vs 快速迭代** — 從 2025-10 到 2026-05 已到 v4.20.3，版本號膨脹快，部分 commands 標記為 Alpha/Experimental，穩定性分層需要用戶自行判斷
