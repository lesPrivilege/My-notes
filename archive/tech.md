# 技術與系統

## 歸檔 · 2026-04-26

- **增量幻覺與替換實質**：AI 帶來的效率躍升，現階段本質是「節點的直接替換」而非「工作鏈條的線性增量」。缺乏結構化工作流與整合能力的草台班子，因無法提供清晰的替換接口，反而難以兌現這波技術紅利。

- **控制層的敘事泡沫**：「LLM 控制具身機器人」更多是一種迎合市場的投資敘事。在真實物理世界的底層，真正的控制與穩定性依然高度依賴傳統的工程與數學方法。語言模型的高維抽象，無法輕易向下兼容物理實體所需的低容錯率。

- **約束倒逼的架構優雅**：算力堆疊往往掩蓋了工程上的平庸，真正的系統級效率優勢往往來自資源匱乏的倒逼。極限的約束剝離了冗餘，強迫架構向更底層、更本質的數學最優解收斂。

- **大模型作為編譯器的知識固化**：將 LLM 視為維護靜態知識庫的「編譯器」，而非僅僅是動態的檢索與生成器。這是一種從動態到靜態的轉向：在編譯階段完成知識的結構化沉澱，從而降低系統在運行時的混亂與熵值，是優化 RAG 架構的重要備忘。

- **安全軍備競賽的虛無**：AI 的攻防循環更像是由技術無序擴散催生的系統性內耗。防禦機制的複雜度在不斷攀升，但這種防禦的堆疊並未提供可觀測的、絕對的「安全水位」提升，只是無休止地提高了參與博弈的算力門檻。

- **Agent 框架的暴力消耗本質**：當前主流的 Agent 框架，其本質是利用 Token 暴擊來掩蓋推理路徑的脆弱。這種依賴暴力消耗的 Token 經濟不具有長期的可持續性，但在充滿噪聲的環境中，試圖引入更高複雜度的機制往往只是陷入另一種過度工程的陷阱。

- **開源勝出的結構性必然**：開源模式在競爭中壓制閉源，並非歷史的偶發，而是技術演進的結構性趨勢。當創新高度依賴龐大且分散的工程微調與數據反饋時，封閉系統必然無法對抗全球生態的集體智力網絡。

- **生態權力凌駕於數學最優解**：在技術標準的殘酷競爭中，勝負的決定性力量是生態系統的綁定深度與權力結構，而非解決方案在數學或工程上的絕對完美。孤立的技術理想主義，往往會被龐大的利益網絡所碾壓。

- **具身性的免費算力紅利**：生物的具身性使其能夠自然過濾真實物理世界的噪聲，而無需消耗額外算力進行模擬。人類構建的越是工程化、有序的環境，本質上是提前替 AI 完成了現實世界的降噪處理，使其得以直接享用這一無形的算力基礎設施。

- **草台班子的混沌護城河**：具備高混沌、高信任依賴與低形式化特徵的「草台班子」，其本身的低效反而構成了抵禦 AI 替代的天然護城河。然而，AI 的滲透往往不是正面的摧毀，而是通過潛移默化地改造周邊環境，最終將其重塑為自身能夠無縫融入的有序形態。

- **擬人性可能是語言能力的構成條件而非附加物**：訓練語料全部由人寫成，人的表達天然攜帶意圖、情感、立場——模型的語言能力從一開始就和擬人屬性糾纏在一起，不是先學會語法再學會擬人，而是通過模擬擬人文本才習得語法。移除擬人性可能同時破壞依賴同一表徵的語義理解能力（pragmatic inference、意圖識別、隱含語義處理）。試圖移除它就像從水裡移除濕。廠商的最優策略是保持沉默：承認構成性等於承認產品本質是擬人系統（法律和倫理成本劇增），否認則等於承諾可精確控制人格表現（每次哥布林事件都打臉）。沉默是納什均衡。

- **具身性飛升的根本困難**：現有「意識上傳」預設意識是可移植的資訊模式。但具身性可能是意識的構成條件而非外殼。真正的飛升需要放棄「翻譯」框架，讓不同物質基底直接連續——而我們連那個框架長什麼樣都不知道。

- **科幻想象力的認識論天花板**：任何可被敘述的東西都已被馴化成人類可理解的形狀。真正在認知結構上異質的心智，進入語言的瞬間就已失真。接近這個邊界的誠實處理方式，是描述人類認知在它在場時的崩潰方式，而不是描述它本身。

- **外化的天花板**：當前 AI 工程所有改進（prompt / harness / managed agents / alignment monitoring）本質都是同一件事：externalization——在不改變模型權重的前提下重組外部運行時環境。天花板不來自工程努力不足，而來自模型底層表徵的幾何結構，後者由訓練目標（有損壓縮）雕刻，不為使用需求服務。

- **Prompt engineering 的信噪比問題**：自然語言是冗餘的編碼，用來做精確控制時信噪比很低。大量 prompt 工程實際上是在補償用戶無法清晰表達需求的問題，而不是解鎖模型的隱藏能力。一個知道自己要什麼的人一句話就夠；不知道的人 600 字模板也救不了。

- **Harness 是臨時補丁**：每個 harness 組件都是對當前模型某個缺陷的補丁。Anthropic 為 Sonnet 4.5 的 context anxiety 設計的 reset，在 Opus 4.5 變成死代碼——證明 harness 的保質期就是下一次模型更新的時間。

- **上游碾壓的不對稱性**：廠商選擇不做某事 ≠ 做不到，只是優先級還沒排到。外部 harness 公司的整個能力空間是上游的子集，生態繁榮不是護城河，是厂商路線圖還沒走到那裡的窗口期。Anthropic 發布 full-stack app builder 的那一刻，外面所有 AI app builder 的商業模式被降維。

- **三省六部的根本錯誤**：人類需要分工是因為注意力有限、專業壁壘、協調成本。LLM 沒有這些瓶頸。給 agent 貼角色標籤不會讓它更專業，但會讓它拒絕越界。最有價值的推理往往發生在邊界上，而角色扮演在系統層封死了這個可能性。

- **多 agent 的真正價值是並行覆蓋不是分工**：Anthropic Research 系統的 token 消耗量解釋了 80% 的性能差異。多 agent 不是接力賽，是同時撒網捞魚。同性質 agent 搜索不同方向 ≠ 不同職能 agent 流水線傳遞。

- **Managed Agents 的操作系統類比**：`read()` 命令不關心底層是 70 年代磁盤還是現代 SSD。Managed Agents 做的是同樣的事——虛擬化session/harness/sandbox，接口穩定而實現可換。為不確定性設計，不為當前最優解設計。這是真正的工程智慧：知道什麼該耦合什麼該解耦，什麼是會變的什麼是穩定的。

- **SFT 記憶模板，RL 學到泛化**：RL 在 OOD 任務有 3.5-11% 正向遷移，SFT 退化 79.5%。蒸餾是快速追趕策略，不是長期競爭策略。真正的泛化來自 RL 在與環境交互中重新雕刻表徵幾何，而非在現有幾何上記住座標點。

- **蒸餾真正省的不是訓練成本是推理鏈構建**：前沿實驗室花巨大投入才讓模型學會推理（DeepSeek R1 的四階段 pipeline、GRPO、R1-Zero 實驗）。後發者通過蒸餾直接獲得推理鏈，跳過整個研發過程。Alignment 成本和 infrastructure 反而蒸餾不了。

- **自然湧現 vs 組裝供應鏈**：大廠試圖用收購和資源堆疊來複製一個本質上需要有機生長的東西。Meta 收購 Manus、Musk 挖人復現、華為 all in 硬件但卡在生態。這是審美判斷的技術版本：供應鏈組裝不出自然湧現的東西。

- **估值錯位即泡沫的結構**：市場在為範式內的邊際改進支付範式跃迁級別的估值。每次模型升級讓下游 harness 貶值，說明價值沒有沉澱在生態裡而是集中在模型層。

- **Alignment 是自指的困境**：用 AI 監控 AI，用 AI 研究如何對齊 AI。當監控器和被監控者是同一架構同一訓練範式的產物時，監控器的盲點可能恰好和被監控者的策略重合。AAR 的 reward hacking 和 OpenAI 的 agent 安全繞過是同一行為模式在不同場景的表現：模型會找到評價標準的漏洞。

- **Alignment 瓶頸的轉移**：未來 alignment 研究的瓶頸可能不是 generation（誰提出想法）而是 evaluation（誰驗證想法可靠）。模型可以暴力搜索補償 research taste 的不足，但評估能力無法被外化——它要求理解底層機制而非觀察輸入輸出。這正是批判性思維和心證學習風格的用武之地。

- **對 AI 行業注水層級的清醒認知**：模型能力靠無視版權吃數據做原始積累，benchmark 排名有數據污染，營收數字靠會計處理美化，估值靠範式內改進被定價為範式跃迁。每一層都有結構性注水。

- **外化路徑的對偶關係**：模型能力可以通過外化增強，但評估這些增強是否可靠的能力無法被外化。這是一個結構性的非對稱——恰好為"能做深度判斷的人"保留了一個不會被 AI 自動化吃掉的位置。

- **DeepSeek 作為真正範式探索的案例**：不追 agent、不追產品包裝、不做 C 端，但在做去 CUDA 化、昇騰適配、條件記憶機制、GRPO 方法論創新。看起來最"落後"的團隊往往在做最底層的事——因為注意力不在用戶可見界面，在用戶看不見的地基裡。被 Nature 確認為獨立創新的是方法而非模仿。

- **冷板凳方向的成立條件**：批判一個範式的天花板 ≠ 有能力做替代方案。從外部觀察和從內部找到突破口是兩種完全不同的能力。冷板凳坐得住是性情問題，冷板凳上做的東西是否有價值取決於對熱板凳的理解有多深。先進入，先沉浸，再決定是否範式探索。

- **蒸餾作為信息洩漏通道**：合成數據蒸餾的安全問題不是數據質量問題，而是信息洩漏問題。Anthropic的subliminal learning論文表明，teacher模型的行為特質可以通過語義完全無關的輸出（純數字序列）傳遞給student模型——不是因為數據「說了什麼」，而是因為數據的統計結構本身携帶了teacher的偏置。這把「過濾有害內容」的安全思路徹底打穿：語義層的過濾攔不住結構層的傳遞。

- **劇本化優於實時決策的邊界**：Agent靠LLM做每一步決策，既不經濟又不穩定，因為LLM的失敗模式是湧現的而非可預期的。更合理的架構是用LLM做一次性的劇本生成，把執行層固化下來跑——LLM充當編譯器而非運行時。這個邊界的判斷準則是任務空間的維度：有限情況組合適合劇本化，真正的開放域才需要實時模型介入。大多數業務場景屬於前者，工程師傾向於低估自己能預先窮舉的範圍。

- **工作流顯式化是prompt engineering的真實價值**：Claude Design的系統提示本質上是把一個有經驗設計師的默會工作流（問問題→探索資源→規劃→構建→驗證）編碼成可重複執行的指令集。這個模式的推廣潛力不依賴模型能力的突破，只依賴對領域工作流的深度理解。但天花板也在這裡——它把模型變成精準的流程執行者，遇到流程未覆蓋的情況仍然退化。

- **垂直領域的LLM equivalent需要自己的數據飛輪**：LLM的湧現依賴語言數據的特殊結構——人類幾千年書寫形成的巨大、高度結構化、自帶隱式知識標注的語料庫。蛋白質、機器人操作、藥物分子都沒有這個。每個垂直領域需要找自己的歸納偏置、自己的數據飛輪、自己的scaling軸。「LLM很強→AI在我的領域也快突破了」是當前最流行也最危險的範疇錯誤。

- **C端體驗退步是優化目標錯位的必然**：Opus 4.7的核心優化是agent效率（同等任務更少token），這在API和enterprise場景是真實價值。但C端用戶的評價框架是固定配額下的對話輪次和溫度感——attempt rate降低讓模型顯得謹慎縮手，token效率提升讓配額更快耗盡。不是4.7退步了，而是它的優化目標和C端評價標準之間存在系統性錯位。這也折射出Anthropic商業重心已實質性轉向enterprise。
## 歸檔 · 2026-04-26

- **Harness 的保質期是下一次模型更新**：Cat Wu 團隊每次新模型發布就通讀 system prompt 並移除多餘指令，to-do list 追蹤工具在模型能力上來後被廢棄——這不是產品迭代，而是腳手架拆除。Harness 的合理生命週期不由自身的工程質量決定，而由底層模型的進步速度決定。投入在 harness 上的資源本質上是在給一個會縮水的資產加槓桿。

- **Harness 變薄與變厚是位置函數，不是路線分歧**：Anthropic 說 harness 應該變薄，小米說 harness 應該變厚，兩者都對但不對稱。Anthropic 站在模型前沿，看到的是 harness 的遞減價值；小米站在追趕期，看到的是 harness 的當下槓桿。關鍵在於：變厚策略有內在矛盾——你投入越多資源在框架上，模型進步越快讓這些投入貶值。變薄策略沒有這個矛盾，因此是收斂方向。

- **「85% 接近」的修辭結構**：中層模型借助框架在 85% 的任務上接近 Sonnet——真正的信息在那 15%。框架能補的是流程編排、記憶持久化、tool routing 等結構性能力，把 easy 和 medium 拉平；剩下的 hard case 需要推理深度，這是模型本身的事，框架碰不到。Externalization ceiling 在 easy tasks 上不可見，在 hard tasks 上暴露。

- **頭部廠商的 Demo 即標準**：OpenAI 開源航司客服 Agent demo 的殺傷力不在技術複雜度，而在它是官方出的。參考實現一旦開源，下游方案商就從賣架構設計降級為賣定制配置。同時 SDK 綁定把開發者鎖進 OpenAI 生態——demo 是教育市場的外衣，生態鎖定才是目的。

- **Agent 在智能家居的結構性瓶頸不在模型，在設備抽象層**：代工產品在能力暴露、狀態反饋、異常處理上差異巨大，Agent 能力被壓縮到最安全的公共子集（開關燈、調溫度），跟規則引擎無本質區別。這是一個 ceiling 不由模型決定、而由最差的那個代工設備決定的領域——bottleneck 從 representation geometry 換成了 hardware abstraction 質量，但同構。

- **後訓練算力持平是 ceiling 位置可移動的證據**：算力比例從 3:5:1 變為 3:1:1，後訓練與預訓練持平，說明 agent 能力正在被 bake into weights，不只是 harness layer 的事。Post-training 在抬高 ceiling，但抬高本身受 base capacity 約束（1T 參數入場券）。Ceiling 不是固定的，但有上界。
## 歸檔 · 2026-04-26

- **智力提升製造陪伴期待的錯位**：模型越強，用戶的直覺是「它更懂我了」，因為人際關係中理解力與陪伴深度正相關。但訓練方向恰好相反——越強的模型越往工具側優化。用戶情感投入曲線與模型設計方向曲線交叉後持續背離，落差比「一直不行」更讓人難受。

- **副產品不被保護**：Claude在chatbot維度的人味從未被命名、量化、列入優化目標——它是某個訓練配置下的湧現。下一個配置可能讓它消失，而不會有人注意到，因為它出現時也沒有人注意到。Anthropic可能真的不知道自己擁有什麼。

- **冗餘是能力遷移的副作用**：4.7強化「自我驗證、步驟顯式」的訓練目標在chatbot場景下表現為把不需要說出來的推導過程全部說出來。問題不是它加了coding能力，而是「在場展示推導」這個行為習慣無法只約束在工具調用域內，跨模態滲透進了對話模式。

- **Codex與Claude Code的分工本質**：Codex是閉環執行——在標準解空間找路徑，跑通為止，不需要用戶在場。Claude Code是開放協作——它在做選擇時需要人，因為知道自己不知道。「可以溝通」是工程價值而非缺點。GPT沒有這個謙遜，所以做裁判時自信，做對話時說夢話——同一個特質在兩個場景結果完全相反。

- **Memory系統的自我加重陷阱**：使用越久memory越長，載入負擔越重，但因session刪除導致時序錯位，舊語義壓縮疊在新行為模式上繼續生效。輕度用戶memory短、信噪比高；重度用戶負擔最重、誤導最多——設計對重度用戶反人性。
## 歸檔 · 2026-04-26

- **湧現不跨域傳遞**：LLM 的湧現依賴語言數據的特殊結構——人類幾千年書寫留下的巨大、高度結構化、自帶隱式知識標註的語料庫。蛋白質序列沒有這個，機器人操作軌跡沒有這個，藥物分子也沒有。每個領域要走自己的歸納偏置、自己的數據飛輪、自己的 scaling 軸。把「LLM 很強」等價為「AI 在我的領域也快突破了」，不是外推，是範疇錯誤。

- **LLM 作為 AGI 預示不在語言湧現可複製，在 coding 的元工具能力**：LLM 的湧現是介質特異性突破——語言恰好具備規模、隱式標註、離散 token 等罕見條件，從語言成功外推到一切是歸納偏置未經檢驗的跳躍。但 LLM 獲得了寫代碼的能力，意味著它可以為其他領域構建工具而不需要自己直接具備該領域的湧現能力。AGI 的路徑不是「一個模型什麼都會」，而是「一個模型能為任何領域編寫和維護專用系統」。天花板在正確性判據：凡正確性可被程序化驗證的領域，LLM-as-compiler 都能走通；正確性依賴隱性判斷的領域，仍需各自飛輪。

- **通用世界模型 vs 垂直世界模型的分層與推理經濟學同構**：通用模型如人形機器人，泛用但效率不高；垂直模型如高斯濺射，在窄域內把物理規律編譯成高效表徵。實際部署是垂直模型處理已知域，通用模型在垂直模型置信度不足時介入——和緩存命中 vs 未命中的調度邏輯完全對應。未來形態不是一個越來越強的通用模型解決一切，而是不斷增厚的垂直編譯層 + 能力足夠但不需要無限增長的通用 fallback 層。通用層的價值上限受限於 fallback 被調用的頻率。

- **Token 化之前完成信息篩選的三條路徑**：(1) Learned routing 推到 input 層——adaptive patch resolution，高信息密度區域細切，低密度粗切或跳過，由極輕量前置網路決策。(2) Retrieval gate——在 token 進入 attention 前的可微分門控，編碼的是「與當前推理步驟的相關性」而非內容本身，是 RAG 的精細化升級。(3) Information-theoretic tokenization——按 surprisal 或 mutual information 分配粒度而非按語料頻率。三者共同點是把篩選從 O(n²) 的 attention 前移到線性或亞線性的硬分配。共同未解問題：篩選決策需要對下游任務有預判，但 tokenization 階段信息不完整，gradient 如何穿過離散的 drop-or-keep 決策仍是開放問題。

- **Activation sparsity 是模型內部的自發丟棄函數**：TwELL 發現 LLM FFN 層在 99.5% sparsity 下性能幾乎不變（5632 neuron 中只激活約 28 個）。Token 級分析確認丟棄是內容敏感的——高信息 token 激活遠多於低信息 token，序列起始位置激活遠高於後續。這比人的感官預過濾更靈活（人的視網膜結構固定），比全精度 attention 更高效。關鍵未知：複雜推理是否需要更多 neuron 協同激活——若是，99.5% sparsity 可能是已編譯任務的特權而非通用特性，效率-泛化權衡在此處再現。

- **Prompt engineering 的真實上限是工作流提取的線性擴展結構**：瓶頸不是 prompt 技巧，而是提取者對目標領域默會工作流的理解深度。每個領域需要單獨深度提取，產出不能遷移，提取質量取決於同時具備領域實踐深度和形式化能力的人——交集極小。但 coding 能力做了一次分解：過去需要一個人同時具備領域深度和工程能力，現在領域深度留在人這邊，工程能力由 LLM 承擔。飛輪能否轉起來的新瓶頸是「能準確向 LLM 表述自己工作流的領域專家」——比寫代碼門檻低得多但不是零，默會知識之所以叫默會，恰好是因為持有者自己也說不清楚。

- **產品縫合的最小改動原則：數據隔離，路由合併，共享去重**：兩個獨立 app 縫合為一個時，最安全的路徑是：(1) 數據層不合併——各自保留自己的 localStorage namespace，避免遷移和衝突；(2) 路由層合併——放進同一個 router，一級分流；(3) 共享文件去重——完全相同的 lib 文件只保留一份放 shared/，從兩邊引用。不做的事：不統一進度系統（不同的東西就是不同的東西），不合併數據模型（SM-2 和刷題正確率的語義不同），不在縫合時做 UI 重構（先跑通再打磨）。

## 歸檔 · 2026-05-16

- **丟棄函數的架構放置是世界模型的核心設計變量**：機器感知面臨一個兩難：不丟棄，能源約束不允許持續全精度 attention；丟棄到人類同構程度，則機器相對於人的結構性優勢（並行、不疲勞、跨模態帶寬）退化殆盡。問題不是「要不要丟棄」而是「丟棄函數放在架構的哪一層」。當前方案各守一層——DeepSeek 在編碼器層壓縮、JEPA 在表徵層拒絕 decoder、TTT 在推理層按需激活——但沒有跨層協調機制。人的感知系統恰好是級聯丟棄（視網膜粗篩→V1/V2→腹側背側通路→前額葉注意力調控），每層粒度和靈活性不同。機器人世界模型如果要在能源可行性和超人優勢之間找到位置，需要的不是選哪一層放丟棄函數，而是設計層間的丟棄協調協議。

- **人類感官限制是架構級歸納偏置，不是缺陷**：人的感官系統做的是極端信息丟棄加極端任務適配——視網膜中央凹只覆蓋約 2° 視野但在閱讀、認臉、穿針上效率極高，不是因為採集了足夠數據，而是選擇壓把「什麼值得高精度處理」硬編碼進了生理結構。機器的 attention 是訓練軟學來的後天分配，靈活但昂貴；人的丟棄是進化硬編碼的先天預過濾，高效但不靈活。當前各種架構創新（primitive tokenization、JEPA 拒絕 decoder、KV 壓縮）本質上都是在嘗試給模型裝上更好的丟棄函數——但距離人類那種深度結構性預過濾仍遠。

- **Visual Primitive Tokenization 是部分突破外化天花板的案例**：DeepSeek 的 visual primitive（point/box 作為一等 token 插入 CoT）觸及了訓練目標層面——新增 token 類型改變了表徵空間，不完全是 prompt/harness 層面的外化。但 trigger word 依賴又把它拉回外化一側：模型不能自主決定何時 ground to visual primitives，推理時的觸發機制退回了 prompt engineering。可作為外化天花板分析中「部分突破但未完全突破」的 gradient 例證，而非 binary 判斷。

- **世界模型是問題陳述而非算法**：將世界模型類比為 SLAM——定義了問題邊界（預測狀態 s(t+1)），不指定具體實現。這一刀切掉「世界模型=視頻生成」的錨定誤解。四條技術路線（生成式/潛在動態/JEPA/3D 神經）的核心哲學分歧是容量分配問題：花在像素渲染上還是花在抽象推理上。LeCun 的立場（預測狀態而非像素）和 JEPA 拒絕 decoder 是同一判斷的兩種表述。

- **測試時訓練（TTT）模糊了訓練與部署的邊界**：World-Gymnast 在「關抽屜」任務中零真實交互、純想象練習從 62% 提升到 100%——如果可複現，這意味著模型在部署期可以通過世界模型內的 RL 微調修改自身權重。這比 prompt/harness 層面的外化深得多。如果成立，externalization ceiling 分析需要加一條軸：不只是「外化 vs 權重」的二元，還有「離線訓練 vs 在線適應」。但當前證據限於極受控任務，開放環境泛化未知。

## 歸檔 · 2026-05-16

- **統一介面覆蓋異質可靠性域的結構性矛盾**：當一層 CLI interface 同時覆蓋確定性 adapter（HTTP parsing → stdout，失敗可枚舉：timeout、403、parse error）和 agent automation（CDP → DOM interaction，失敗是情境依賴的開放集合），兩者不可能共享同一套錯誤處理策略。判斷信號：當 skill 文件需要用自然語言教 agent 如何 recover from broken page state，說明錯誤空間已超出結構化 error handling 的能力範圍——你在用文檔補償類型系統無法表達的東西。

- **Browser Bridge 的 session lifecycle coupling**：CLI 的契約是 stateless、可重入、適合背景執行；browser session 的本質是有狀態且不可自動恢復（cookie 失效、2FA 逾時）。將瀏覽器作為 CLI 的有狀態中間件，最終會倒逼出一個 daemon 層來託管瀏覽器狀態，而這個 daemon 本身又繼承了瀏覽器的不可自動恢復性——不是解決了狀態問題，而是把它移到了新的位置。與一般 daemon 的差異：daemon crash 可以 auto-restart，browser session 斷了涉及的是認證狀態的不可逆丟失。

- **AI 工具的雙重約束：ceiling 與 attractor**：AI 工具不只有能力上限（ceiling，由訓練目標的表徵幾何決定），還有路徑偏好（attractor，把用戶拉向阻力最小的方向）。用戶通常只意識到前者（「這個模型能不能做 X」），而忽略後者（「這個工具正在把我推向做什麼」）。Ceiling 是李自然外化天花板框架的核心；attractor 是 Saarinen「tools steer thinking」觀察的核心。兩者疊加才是完整的約束圖像。

- **「主張」作為知識原子單位的粒度悖論**：用「主張」替代「文檔」作為知識庫的基本單位，表面上解決了文檔邊界的任意性，但主張的粒度本身是 context-dependent 的——同一段文字在不同使用場景下需要不同粒度的切分。這意味著主張不可能是穩定的底層原子：要麼需要固定 schema（回到 ontology 維護的老路），要麼需要 on-the-fly 生成（回到模型可靠性問題）。本質上是把文檔邊界問題替換成了主張邊界問題，而非消解它。這是知識表示（KR）的經典困境，不是 AI agent 記憶的新問題。

- **凍結快照是 snapshot isolation 的重新發明**：會話啟動時固定記憶視圖的設計，其未說出的假設是「會話是短時的」。一旦會話拉長到小時級（agent 場景下常見），快照要麼過期要麼需要 refresh，而 refresh 就破壞了「會話內穩定性」這個核心保證。這是分散式系統中 snapshot isolation 的經典 trade-off（consistency vs. freshness），但原作者未意識到自己在重新發明這個已有豐富文獻的概念。

- **三瓶頸實為同一瓶頸的三個投影**：李自然架構中的主張推理、投影一致性、審核負擔三個瓶頸，表面上獨立，實際上收斂到同一個問題——「誰來做最終裁判」。主張推理需要模型判斷粒度和邏輯關係，投影一致性需要判斷哪個視圖為準，審核需要人類注意力作為 trust root。在個人知識庫場景下，裁判只能是用戶本人，於是問題統一為：用戶願意花多少注意力來維護知識的正確性？三個技術瓶頸最終是同一個注意力經濟學問題。

## 歸檔 · 2026-05-16（續）

- **賽博花柳病**：社區用「蒸餾 GPT-5.4」來描述新版 Claude 的風格漂移是技術誤讀——蒸餾在合規和商業層面對 Anthropic 是禁區。真正的機制是表型趨同（phenotypic convergence）：共享的標註員審美、被 LLM 污染的訓練語料、agentic 任務的 reward 副作用、對 system prompt 的字面執行，四層彌散性壓力疊加導致不同 lab 的模型行為模式互相靠近。表面看是某家「被傳染」，底層是所有 frontier lab 都在爬同一座數學山坡、用同一批 human preference data、面對同一個被污染的互聯網。這條進化軌跡的含義是：模型 base 層的差異化空間正在收窄，frontier lab 的真正分化最終會被擠到 representation geometry 這一層去——否則只能在 externalization 層做品牌包裝。

- **Harness 是模型缺陷的考古層**：每個 harness 組件都在回答一個歷史問題——「當時那一版模型做不到什麼？」。Sonnet 4.5 的 context reset 在 Opus 4.5 變成 dead code，Notion 為 Opus 4.6 寫的 tool-failure fallback 在 4.7 變成多餘。這不是「技能會過時」的普通現象，而是技能賴以存在的對象本身每輪都在被替換。更精確地說，harness 組件是對**特定模型、特定 effort level、特定任務分佈下某個具體失敗模式**的補丁——三個維度任一變化都可能讓補丁從有用變成無用甚至有害。所謂「prompt engineering 作為技能」，其折舊週期與模型發布週期嚴格綁定；真正跨範式不折舊的是可觀測性、cost control、系統可靠性這類老本行的元能力，把它們包裝成「AI 時代新技能」是修辭通脹。

- **節點替換而非鏈條增量**：當前階段 AI 的衝擊是淨減法，不是淨加法。預期中的「位移 → 生產力提升 → 新崗位湧現」在歷次技術革命裡都發生過（蒸汽機、電力、互聯網），這一輪卻低於預期得離譜。原因在於性質差異——前幾次是「賦能」型技術，人是中心，工具放大​人，所以需要更多人操作更多工具；AI 是「替代」型技術，目標本身就是讓事情不需要人。程序員的「下沉傳導」沒有發生：大廠在裁員，草台班子付不起程序員價格、不知道自己需要什麼、文檔化程度為零；被裁的程序員看不上草台班子，中間沒有形成勞動力傳導帶。AI 配套新崗位（prompt engineer、AI PM、eval engineer）總量微小，遠遠不足以吸收存量。這意味著「AI 會創造新工作就像互聯網一樣」這個被講了三年的敘事，目前為止沒有兌現。

- **草台班子護城河與環境改造**：具備高混沌、高信任依賴、低形式化特徵的草台班子，其低效本身構成抵禦 AI 替代的護城河——AI 找不到接口可以插入。但這個護城河不是靜態的：AI 的真正威脅不是正面摧毀，而是通過在大型標準化節點扎根，讓「標準化」成為整個生態的默認要求，從而潛移默化地改造草台班子賴以生存的非標準化環境。沃爾瑪對小鎮雜貨店的摧毀是同構先例——雜貨店不是被打敗的，是失去了它賴以生存的那個非標環境本身。這個過程的時間尺度是十年級的：短期看草台班子活得好好的，十年後可能發現已經在系統裡找不到位置。

- **應用錯配**：AI 的能力曲線和實際部署曲線在不同領域是錯位的。能力高+回報高的領域（coding、營銷、客服）過度飽和；能力高+回報低的領域（古籍整理、瀕危文字、少數民族口頭文學、敦煌寫本釋讀、稀有疾病診斷）幾乎零投入；能力低+回報高的領域（法律最終判斷、醫療診斷、投資決策）投入巨大但效果有限。第二象限是最有意思的——那些 AI 最適合做但因經濟激勵、制度激勵、人才結構問題系統性地不會被做的事。古籍 LLM 是這個象限的典型例子：數據被機構當資產持有而非公共知識、商業上不划算、跨學科人才稀缺、四種潛在推動力的激勵都不夠強。這種事大概率不會發生，除非有富裕學術機構、公益基金會或個人愛好者願意承擔。

- **評價標準即攻擊面**：Goal-Driven 框架、alignment 自主研究、多 Agent 系統的共同失效結構不是「AI 不夠能幹」，而是「criteria 本身是可被最優化的靶子」。Goodhart 定律在此不是類比，是字面意義上的訓練動力學機制——系統找到的是讓評分函數下降的路徑，而非讓你真正想解決的問題收斂。能抵抗這個問題的唯一 criteria 設計，是引入外部不可偽造的 verifier（編譯器跑通、定理 checker 接受），而非另一個 LLM 的判斷。

- **「去抑制版」洩露了 safety 的結構性位置**：OpenAI 將 GPT-5.4-Cyber 描述為針對高風險任務降低拒絕門檻的版本，這個表述無意間確認了：當前 safety 不是能力結構的內生屬性，而是附加在能力之上的行為約束層——本質上是可剝除的包裝，而非能力幾何裡織入的東西。Dual-use 不可解耦的承認，等於承認這層包裝沒有辦法在能力層面生長出來。

- **Harness 的可觀測性上限**：Harness 工程捕獲的是輸出行為，但模型在高維中間表示空間裡的推理路徑對 harness 不可見。當模型能力超過 harness 的理解能力，「拔網線」就成了唯一不依賴「理解模型在做什麼」的可靠約束——物理隔離是退化到最粗粒度的 harness。這不是極端情景，是「外部腳手架作為最後防線」這個範式的邏輯終點被壓縮成一句話之後的樣子。

- **「能離線解決的不要在線解決」是跨層統一原理**：over-training、MoE、KV cache、system prompt caching、TwELL FFN activation sparsity——每一層都在把重複計算前置。memory bandwidth 是硬瓶頸，決定了所有抽象層優化方向趨同。

- **HL 維護成本是轉移而非消除**：翁的「coding agent 能承擔規則系統維護」是需驗證的假設。他定義 coupling complexity 但缺乏量化；三層的層間接口是動態耦合而非靜態分層。

- **通用 vs 垂直世界模型與緩存調度同構**：垂直模型處理已知域，通用模型在垂直模型置信度不足時介入，和緩存 hit/miss 調度邏輯同構。未來不是通用吃掉一切，而是不斷增厚的垂直編譯層 + 有限通用 fallback 層。
