# 生活決策與心智工具

## 歸檔 · 2026-04-26

- **「優惠」是讓價格替你做決策**：需求和價格是兩個獨立問題，打折只影響後者，不影響前者。被優惠觸發的購買，是決策權的讓渡。

- **經典產品的識別標誌**：有老用戶在認真談論它的缺點。沒有缺點討論的產品，要麼沒人真的在用，要麼是在營銷。

- **減少品類比減少數量更有效**：決定「不進入這個品類」，整個品類的所有營銷對你永久失效。

- **瑣事會自我增殖**：處理一件時會發現另一件，疏離感的作用是在蔓延發生前切斷它：記下來，但現在不處理。

- **「今天到這裡結束」和「今天做夠了」是兩個本質不同的理由**：前者是邊界，後者是評判。用前者作為睡眠的觸發條件，不用後者。

- **樣板間的真實價值是「呈現方式」而非「物品清單」**：好看的空間背後的規律通常是：東西少、有視覺焦點、色調克制。這些是審美能力，與購買無關。

- **系統在狀態好時替狀態差的自己做決策**：這是真正可靠的自我支持，不是靠當下的意志力，而是靠提前的結構設計。

- **碎片時間的默認值應該是留白，不是填滿**：主動選擇播客/音樂/魔方，而不是被動接受推薦流。「看才需要理由」而不是「不看才需要理由」。

- **問卷結果可能精準地讀到認知傾向卻誤讀動機**：被測為「精緻利己主義者」的反差——問卷讀到的是「面對假設決策題時本能選最優解的還原型分析傾向」，但實際行動的驅動不是利益最大化而是意義感（反覆拒絕更方便的個人福祉路徑）。這說明分析能力和價值取向是兩個獨立維度，測試常把前者讀成後者。
-  **「淺嘗輒止」不是失敗模式，是成本最優的探測策略**：回顧工具鏈搭建過程——每次剛開始做，不通，放下；某個契機再嘗試，通了。表面看是意志力不足導致的中斷，實際結構是：在基礎設施（模型能力、文檔質量、社區生態）尚未成熟時投入的邊際回報極低，等待成本遠低於硬磨成本。關鍵不是堅持，而是保持回來嘗試的意願——前者消耗意志力，後者只需要一個低成本的觸發機制（看到一篇文章、一個帖子、一次對話）。這與「系統穩定性而非意志力」（#2）的設計哲學一致。
## 歸檔 · 2026-04-28

- **代償優於隔斷**：專注軟件和番茄鐘試圖約束行為表層，但行為會繞過約束自行代償——擋住一個入口，注意力從另一個入口流向社媒。有效的干預不在枝葉上綁繩子，而在改變產生行為的底層狀態：生化基礎設施（睡眠、運動、飲食）改變的是土壤，不是枝葉。接受前者、拒絕後者，不是原則潔癖，是對因果層級的判斷——在因上做功，不在果上打補丁。

- **敘事是事後追認的奢侈品**：經歷中的真實收獲（習慣、祛魅、技能、閱歷）是帶走的東西，不是那段經歷的「意義」。意義需要後續成果來追認，在成果出現之前預支敘事是自欺。合理化隨時可以做，但它只在跨過門檻之後才兌現為真正的註腳，之前只是止痛劑。

- **過渡期的低效不可用終態標準衡量**：事務性打斷佔用的是決策帶寬而非感官通道，無法像環境噪聲一樣屏蔽。在結構未就位的過渡期內，零星推進與系統訓練之間是質的差異，不是量的差異。正確的做法不是強行執行終態方法論（間隔記憶、系統訓練），而是承認當前只能做當前能做的事，守住方向，不讓低效感反噬動力。
## 歸檔 · 2026-04-28

- **認知靜息態作為獨立功能模塊**：規則明確、判斷範圍窄、材料已結構化的活動——校勘、過劃線、整理Xmind分支——不是學習也不是娛樂，是第三類。它的功能是重置神經化學狀態，不是產出。把它識別為獨立模塊並固定時段，才能讓生理化學效益穩定可複用；「有空就做」的隨機性會讓效益消失。

- **舊知識領地的結構化保留原則**：已讀過的材料不應因方向轉換而完全廢棄，但保留的形式應去除學術體系的研究義務，僅保留個人思維和審美的輕度輸入輸出。語義壓縮可以外包，審核判斷留給自己。這既維持與舊領地的連接，又不構成新的負擔。

- **意義真空下的啟動成本機制**：評估系統持續在後台運行，所有活動都需要通過「值得做」的篩選才能獲得啟動資源。獨處時這個聲音可被忽略，戶外時環境的社交預設把它激活到前台，導致同樣的空閒在室內可接受、在戶外產生負罪感和空虛感疊加。解決方向不是修復「享受空閒」的能力，而是給戶外活動賦予功能性身份，使評估系統能找到它的位置。
## 歸檔 · 2026-04-28

- **稀缺资源的阶段性迁移**：从"在匮乏中靠朴素热情把简单的事做到极致"到"在复杂环境中靠判断力找到正确的事然后调用资源"——前者的瓶颈是意志力，后者的瓶颈是判断力。投入重建基础、理解底层结构，正是后一种模式下对真正稀缺资源的校准。
## 歸檔 · 2026-04-30

- **搬家過渡期的碎片時間最適合 vibe coding**：傳統學習需要持續集中，搬家期間做不到。Vibe coding 項目可以在碎片時段推進，目標不是產出代碼而是建立對開發流程和軟件工程的體感。選真實需求的項目（PKM、學習工具）而非練手項目（todo app），因為你會在意產品決策而不只是代碼能不能跑。

- **API key 泄露是操作流程缺脫敏步驟的問題**：Agent 的思考過程會把環境變量裡的敏感信息寫進輸出（debug API 連接時自然會讀 env 並打印）。風險不在本地 session 讀到 key，而在把 agent 日志原樣貼到雲端對話。防護措施：貼日志前 grep 敏感前綴（sk-、tp-）；代碼從環境變量讀 key 不硬編碼；.gitignore 排除 .env 和日志文件。
## 歸檔 · 2026-05-02

- **影院作為外部完全托管的沉浸**：與心證式學習形成對照——同樣的深度投入，學習是主動的、有摩擦的、需要不斷自我驅動；影院是被動接收、高密度、不需要自我管理。出來後「生活應該怎樣做」的感覺，是短暫體驗到「全然投入而不疲憊」的狀態，然後意識到日常裡這種狀態太少了。

- **技法可見性決定體驗類型**：能觸發「生活應該怎樣做」的，是技法透明到讓你忘掉在看電影的片子——你在裡面作為一個人在經歷。一旦技法被看見，就從體驗者變成鑒賞者，愉悅仍在但性質完全不同。條件不是「好電影」，而是「透明」。

- **不留存的純休息**：很多觀影幾乎完全忘記、也並非經典，但在當時場內確實得到了正向支持。從中取用的不是信息，而是一段消耗即完成、不留痕跡也沒關係的純休息——恰好是日常裡少數不需要積累、不需要產出的場景。

## 歸檔 · 2026-05-08

- **個人 harness engineering 的設計目標是被 internalize 掉**：與 AI 的 system prompt 補丁不同，人的外部規則如果運行足夠久可以內化為習慣和直覺——harness 被吸收進「權重」。一條規則三個月後還需顯式提醒才能執行，要麼規則本身有問題，要麼尚未理解其背後邏輯。但初期比 AI 更難穩定：人不會遵循指令，生理化學指標混沌。知道自己不會遵循指令這個認知本身若被吸收，改變的不是行為而是設計系統時的假設——不再把自己當作會執行指令的 agent 來編程，而是當作會漂移、會找藉口、會被生理狀態劫持的系統做容錯設計。

- **機器學習作為人的仿生武術**：象形拳的本質不是變成那個動物，是從異質結構提取可遷移的力學原理。Reward hacking、distribution shift、overfitting 這些概念一旦被識別，在人的認知和行為裡到處可見——只是之前沒有這套語言來指認。反向也成立：用人的經驗理解機器的局限。這種跨域類比在學術分工視角下顯得不夠嚴謹，但實際效用往往高於純域內分析，因為它繞過了域內盲區。

## 歸檔 · 2026-05-16

- **自洽配比作為購買判準**：購買決策中的不適感，來源不是某個維度的絕對高低，而是各維度比例是否有機。配置失衡的中間款讓人不適，不是因為參數差，而是它的結構邏輯依賴廠商的人為切割而非產品內在的自洽——局部被拔高意味著整體不再是一個收斂的系統。

- **冗餘與殘缺是對稱的結構錯誤**：「做滿」不是美德，而是某個維度脫離系統需求的自我膨脹。冗餘和殘缺在結構意義上是同一類問題：局部與整體的張力沒有收斂。和諧不要求每個維度最大化，要求的是沒有哪個部分在空轉或拖累。

- **集合層面的對稱性可消解個體的結構畸形**：16+256單獨存在時讓人不適，引入12+512後集合作為整體重獲平衡，不適被中和。這說明評估單位是關係結構而非條目屬性——局部的「畸形」可被整體的對稱性吸收。

## 歸檔 · 2026-05-16（續）

- **資源獲取的階段切換**：專業資源的可得性隨社交位置而變。初級階段公開通行資源足夠覆蓋需求（王道、CLRS、Sipser、MIT OCW）；進入 peer 階段後，真正稀缺的不是公開材料而是私下流通的筆記、師門內部的硬盤傳承、作者直接的 preprint 分享、實驗室共享盤——這些東西囤不到也不需要囤，進圈以後問一聲就有。所以現階段大規模囤書是過度準備，信息價值會隨著自己進入學術圈而急劇貶值。唯一例外是冷門方向的老書（60 年代蘇聯數學教材、絕版 lecture notes 這類）——師兄師姐未必有、學術圈流通弱，遇到想要的時候機會主義式抓下來，但不必系統性囤積。
