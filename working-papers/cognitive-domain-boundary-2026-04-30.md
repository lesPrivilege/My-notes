# 认知边界与领域特殊性：通用智能幻觉的批判

> Working Paper · Draft · 2026-04-30 (rewritten 2026-05-12; revised 2026-05-20; E1 S-grade rewrite 2026-05-21)
> Source notes: 13 entries from mind.md, method.md, tech.md, power.md

---

## 主张

LLM 的自然语言界面制造了一种「通用智能」的强烈幻觉，使用户——包括领域顶尖专家——系统性地误判其能力边界。这种幻觉的核心机制有三层：界面层的通用性被错误映射为能力层的通用性；用户越不懂某个领域，越缺少检测错误的能力，因而越觉得模型强；模型自身又缺少稳定的边界自知，无法可靠提示「我已经离开能力区间」。

因此，真正需要建立的不是「AI 能不能跨域」的二元判断，而是一套边界判准：某种能力能否迁移，取决于目标领域是否具备可程序化验证的正确性判据、可自转的数据飞轮、可形式化的工具/工作流层，以及与原领域相容的表示结构。语言涌现不可直接外推到蛋白质、机器人、药物分子；但 coding 是关键例外，因为它不是普通垂直领域，而是能为其他领域生产专用系统的元工具层。将某一领域的成功外推至另一领域，本质上是把「界面」误当「能力」、把「结果相似」误当「机制相同」、把「可调用工具」误当「已内化理解」。

## 论据链

### E1. 通用性幻觉的机制——界面与能力的错位 [S]

> *来源：mind.md —— 领域内专家在领域外的认知退化；Gell-Mann Amnesia × Dunning-Kruger 的交叉效應*
> *成熟度：S*

自然语言界面的通用性与底层能力的通用性是两件独立的事。LLM 能用同一个界面回答蛋白质折叠、机器人控制、古籍校勘的问题，但这只说明语言空间的统计覆盖率高，不说明每个领域的输出都可靠。界面层的无差别流畅性被系统性地误读为能力层的无差别可靠性——这是幻觉的机制核心。

这一误读有认知科学层面的结构性支撑：Gell-Mann Amnesia 效应（对自己熟悉领域的媒体报道发现错误后，翻到下一页陌生领域立刻恢复信任）与 Dunning-Kruger 效应（越不懂某领域，越无法检测该领域的错误）交叉作用。结果是：AI 在用户不懂的领域看起来最强，恰恰因为用户在那些领域没有错误检测能力。专家在自己领域能看见 LLM 输出中的缝隙、滑坡和虚构细节；切换到陌生领域后，检测器失效，流畅输出重新获得可信度。

这意味着通用性幻觉不是偶然的用户误判，而是界面设计 × 认知偏差的必然产物。即使是领域顶尖专家，一旦离开自己的判断力边界，也会退化为普通用户——因为离开的不是智力，而是领域特异性的错误检测基础设施。

心证方法论在此的功能不是保守主义，而是反 Gell-Mann Amnesia 的认知装置：拒绝接受黑箱输出，要求在自己的结构里重建一遍，本质上是人为维持领域检测器的活跃状态。

**论据功能**：框架奠基。建立「界面层 vs 能力层」的区分，从认知科学机制（Gell-Mann × DK）推导出通用性幻觉的结构性必然，不依赖特定案例即可成立。

### E2. 人类认知能力的领域边界——以心证为例

> *来源：method.md —— 心证的适用边界；tech.md —— 弱模型不知道自己到了能力边界*

人类的认知工具并非普适。心证能力在初等数学/几何成立，是因为抽象层次恰好在人类直觉可处理的范围内。高阶数学里直感缺失，不是理解出了问题，而是那个层次结构性地超出直觉可触及的边界——数学家也一样。「不能心证」≠「没懂」。

这个结构延伸到认知能力的更一般特性：演绎系统与经验库的区分（method.md）——数学技巧分两类：一类有底层几何/逻辑必然性（值得追直感），一类是「有人试过发现有效」的 pattern（正确训练方式是曝光+认出形式，强行追底层逻辑会持续消耗且找不到）。对经验库类技巧，「为什么用它」的答案就是「见过足够多次」，不需要更深的理由。

心证与 LLM 使用的认识论冲突进一步说明：LLM 的正确用法更像「语义级 grep」，而不是可替代心证的 tutor。弱校准是结构性的——模型在检索不到答案时会沿 context 的语义场编出合理答案，且这种滑移无法被 prompt 层完全补偿。用户之所以信任陌生领域中的 LLM 回答，正是因为自己无法感知模型何时从「检索」滑入「编造」。

**论据功能**：提供人类认知边界的具体案例。心证的结构性边界（初等数学成立 vs 高阶数学失效）与 LLM 涌现的领域依赖性是同构的——两者都不是简单的能力不足，而是认知工具、校准机制与问题结构不匹配。

### E3. AI 涌现能力的领域依赖性——数据结构与表示结构

> *来源：tech.md —— 涌现不跨域传递；垂直领域涌现不可从 LLM 外推；像素序列与力矩序列的不可对齐性；功能等价不蕴含机制等价*

LLM 的涌现依赖语言数据的特殊结构——人类几千年书写留下的巨大、高度结构化、自带隐式知识标注的语料库。蛋白质序列没有这个，机器人操作轨迹没有这个，药物分子也没有。每个领域要走自己的归纳偏置、自己的数据飞轮、自己的 scaling 轴。把「LLM 很强」等价为「AI 在我的领域也快突破了」，不是外推，是范畴错误。

垂直领域涌现不可从 LLM 外推（tech.md）不只是因为数据量不足，更根本的原因是介质结构的不可复制性。通用层收益（chatbot、文献处理、代码）搭的是 LLM 主线便车，会沉淀为基础设施；专门的涌现级突破则路径各自独立。从「语言领域可十亿次复制」跳到「星辰大海」，中间跳过了整个归纳偏置迁移问题。

新 index 对这个点给出了更硬的技术版本：视频生成模型学的是像素在时空上的统计规律，不编码质量、摩擦、扭矩上限；「视频质量够高就能对齐机器人动作」省略了逆运动学、接触力建模、闭环反馈、本体差异等中间层。功能等价也不蕴含机制等价：即使能在行为输出层面逼近某个工匠技能，内部也不是同一种肌肉记忆、附带觉知和直觉结构；每个技能都需要自己的传感方案、状态空间定义和奖励函数设计。成本结构是逐领域重建，而不是预训练一个通用具身基座后自然迁移。

**论据功能**：将 E1（界面幻觉）和 E2（人类认知边界）的分析扩展到 AI 技术本身。LLM 的涌现严格依赖语言数据的特定结构，这个依赖性与人类认知工具的领域边界是同构的——都是认知工具与问题结构匹配度的问题。

### E4. 边界判准——coding 作为元工具能力，而非普通反例

> *来源：tech.md —— LLM 作为 AGI 预示不在语言涌现可复制，在 coding 的元工具能力；Coding 域飞轮的三层基础设施结构；自然语言 vs. 多模态的问题性质差异；method.md —— 工程优化是对约束面的适配而非通用属性*

旧稿的弱点是把「涌现不跨域传递」说得太像绝对否定。新的 index 要求更精确：语言涌现不可直接复制，但 LLM 获得 coding 能力后，产生了一个特殊桥梁。AGI 的可行路径未必是「一个模型什么都会」，而可能是「一个模型能为任何领域编写和维护专用系统」。换句话说，coding 不是又一个垂直领域，而是把通用能力编译成专用系统的元工具层。

这个例外有严格边界。凡正确性可被程序化验证的领域，LLM-as-compiler 更容易走通；正确性依赖隐性判断的领域，仍需各自的数据飞轮和领域判准。Coding 域之所以形成局部飞轮，不是因为模型能力神秘地跨域了，而是因为它同时具备三层基础设施：context 采集层（代码库、issue、历史变更）、微调信号层（issue → PR 的天然输入/输出/ground truth）、验证闭环层（测试、type checker、compiler）。这些条件在法律、医疗、机器人、古籍校勘等领域往往不完整。

因此，边界判准可以暂时写成四问：

1. **正确性判据**：结果能否被程序化、低成本、可重复地验证？
2. **数据飞轮**：领域是否天然产生可回收的输入、输出和反馈信号？
3. **表示结构**：目标领域的状态空间是否与语言/代码 token 表示相容，还是需要力、触觉、空间、时间等不可压扁的结构？
4. **工具层位置**：LLM 是直接替代领域能力，还是在为领域能力生产工具、脚本、验证器和工作流？

自然语言生成「只剩工程问题」而多模态生成仍是科学问题，这从模型训练一线印证了同一判准：不同领域不是发展阶段早晚的问题，而是问题性质、验证器成熟度和数据飞轮结构不同。

**论据功能**：修正 E3 的过强表述。论文主张不是「AI 不能跨域」，而是「跨域必须经过判准」。coding 是边界条件，不是反证；它说明通用层的真正价值可能在编译能力，而不是在直接吞掉所有垂直领域。

## 已知弱点

### W1. 案例的代表性与深度

施一公、王兴兴的案例仍是概括性描述，缺乏具体事件细节和直接证据链。Gell-Mann Amnesia × Dunning-Kruger 可以补足机制解释，但不能替代案例证据。需要更大样本的系统性研究来确认「领域外判断力退化」的普遍程度。

**严重程度**：中。

### W2. coding 例外已经纳入，但边界仍需量化

修订版已将 coding 作为元工具层纳入 E4，但这只是定性修正。真正困难的问题仍是：哪些领域的正确性判据足够清晰，哪些领域的数据飞轮足够自转，哪些领域只能形成 demo 而无法沉淀为可维护系统？边界目前仍以结构判断为主，缺少定量指标。

**严重程度**：中。边界定在哪里是关于这个论文最需要回答的问题。

### W3. 理论框架的整合性不足

四个论据点（界面幻觉、认知边界、数据结构、跨域判准）分别来自不同领域，虽共同指向「边界」主题，但尚未整合成一个层次分明的统一理论框架。比如：人类心证的领域依赖性与 LLM 涌现的领域依赖性是同一结构的不同实例（离散化边界的信息损失），还是只是类比？论文的当前结构仍偏并列，E4 只是给出了判准雏形。

**严重程度**：低。并列论证在当前阶段足够，后续可升级为统一框架。

### W4. 与编译经济学的关系需要再收束

`compile-economy-2026-05-20` 已经把「通用能力 → 专用系统」写成更完整的分层治理框架。本论文现在与它共享 E4 的 LLM-as-compiler 方向，但侧重点不同：本论文讨论误判边界，编译经济学讨论成本和部署架构。后续需要明确两篇的分工，避免重复展开。

**严重程度**：低。当前作为互补关系成立，但如果继续扩写，需保持边界。
