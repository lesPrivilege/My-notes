- **LLM參數層的知識論異態**：預訓練權重中的知識滿足顯性知識的生產條件（來源為形式化語料、編碼過程為確定性數學運算），卻不滿足顯性知識的可檢索條件（無法指認哪組參數對應哪條知識）；反過來稱其為默會知識也不成立，因為它缺乏Polanyi框架要求的具身性與附帶覺知結構。這不是尚未被歸類的邊緣案例，而是一個需要獨立命名的第三態——形式上顯性、操作上不透明的潛態知識。這使得「LLM是顯性知識的勝利」這類敘事自我拆解：LLM最強的能力恰恰來自這個逃逸出顯性／默會二分法的參數層。
