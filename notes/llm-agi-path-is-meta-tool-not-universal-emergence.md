title: "LLM 作為 AGI 預示不在語言湧現可複製，在 coding 的元工具能力"
date: 2026-05-11
source: tech
---

- **LLM 作為 AGI 預示不在語言湧現可複製，在 coding 的元工具能力**：LLM 的湧現是介質特異性突破——語言恰好具備規模、隱式標註、離散 token 等罕見條件，從語言成功外推到一切是歸納偏置未經檢驗的跳躍。但 LLM 獲得了寫代碼的能力，意味著它可以為其他領域構建工具而不需要自己直接具備該領域的湧現能力。AGI 的路徑不是「一個模型什麼都會」，而是「一個模型能為任何領域編寫和維護專用系統」。天花板在正確性判據：凡正確性可被程序化驗證的領域，LLM-as-compiler 都能走通；正確性依賴隱性判斷的領域，仍需各自飛輪。
